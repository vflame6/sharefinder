# Security policy

## Supported versions

Security fixes go into the latest release. Please update to it before
reporting a problem.

## Reporting a vulnerability

Report vulnerabilities in sharefinder privately through
[GitHub Security Advisories](https://github.com/vflame6/sharefinder/security/advisories/new).
Do not open a public issue.

Please include the sharefinder version (`sharefinder --version`), the command
line with credentials removed, what happened and what you expected. You will
get an answer within a week.

sharefinder is a tool for authorised security testing. Issues about what it
can find on a network you test are not vulnerabilities in sharefinder; issues
where sharefinder itself harms the tester or the tested network (for example
leaking credentials, locking out accounts or leaving files behind) are.
